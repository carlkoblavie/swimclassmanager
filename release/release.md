# What's new

## v0.2

**17 August 2026**

The main teaching, enrolment, and term-payment workflow is now in one place.

| Update                                         | What's included                                                                                                                                        |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **NEW** — Curriculum stages and skills         | Organise programmes into levels and stages, define stage skills with pass criteria, and reuse curriculum content as classes progress.                  |
| **NEW** — Skills and activity banks            | Build school-managed skills, skill families, activities, categories, age groups, and bank packs for consistent lesson planning.                        |
| **NEW** — Stage-based class setup              | Create classes within a curriculum stage with their level, term, skills, duration, capacity, and class-specific options.                               |
| **NEW** — Lesson generation across a term      | Generate a date range of lessons with recurring weekdays, duration, previews, and continuous lesson numbers that do not restart each month.            |
| **NEW** — Lesson activities and copying        | Add bank or custom activities, equipment, objectives, notes, observations, and conclusions, then copy activities into empty lessons in the same stage. |
| **NEW** — Lesson list and detail views         | Review lessons by class, level, stage, date, activity status, and instructor in list or calendar view, with focused detail and editing screens.        |
| **NEW** — Instructor staffing                  | Invite instructors and assistant coaches, assign lead and supporting instructors, bulk-assign staffing, and see assignments on lessons.                |
| **NEW** — Learner enrolment workspace          | Work from Unplaced, Enrolled, or All learners, search and filter by level, and place one learner or a group into a class.                              |
| **NEW** — Choose the lessons a learner attends | Select the learner's lessons during enrolment, set the date they join, and keep attendance and progress tied to that starting point.                   |
| **NEW** — Class changes and make-ups           | Move learners between classes, change selected lessons, add a make-up lesson, or withdraw a learner while retaining their record.                      |
| **NEW** — Term-based payment tracking          | Track pending invoices, sent invoices, part-paid terms, paid terms, and closed enquiries with payment records tied to the school term.                 |
| **NEW** — Part payments and enrolment          | Record a payment amount for a learner and term, see the remaining balance, and continue placing learners even when the term is only part paid.         |
| **IMPROVED** — Dashboard and daily priorities  | See sign-ups, enrolments, lessons, instructors, revenue, today's schedule, overdue invoices, unstaffed lessons, and other work needing attention.      |
| **IMPROVED** — Skills shown with pass criteria | Lesson skills now use numbered tiles with clear pass criteria, making assessment easier to scan during and after a lesson.                             |
| **IMPROVED** — Safer roles and actions         | Instructor, manager, and administrator access is reflected in the available screens and actions, including lesson generation and learner withdrawal.   |
| **IMPROVED** — Cancelled class handling        | Cancelled classes stay out of active lesson generation and new learner placement, keeping schedules and enrolments consistent.                         |

### Coming next

Payment history, guardian notifications, payment-based progression controls, and attendance policy tools will build on this foundation.
