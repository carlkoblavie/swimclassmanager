# Delta — billing

## ADDED

### Premium clubs unlock platform default skills

- Given a club has premium status, when its Administrator or Head Coach defines class stages, then platform default skills are available for that club to use.
- Given a club does not have premium status, when its Administrator or Head Coach defines class stages, then platform default skills are not available for that club to use.
